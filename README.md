# 🎬 Netflix Front Page Clone (HTML & CSS)

A frontend-only clone of the **Netflix landing page**, built using **pure HTML and CSS**. This project focuses on replicating the visual layout of Netflix’s homepage to practice responsive design and modern styling techniques.

## 🌟 Features

- Netflix-style hero banner with background image
- Navigation bar with logo and sign-in button
- Responsive layout using Flexbox and Media Queries
- Clean and minimal design structure

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
